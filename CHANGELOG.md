# Changelog

## [v6.0.0] - 2026-08-15

### Added & Enhanced
- **Rapid Customer Count-Up Animation**: Added a smooth, 1-second animated count-up effect (1 → 100+ Customers) using `requestAnimationFrame` with ease-out cubic deceleration, memory leak protection, and `prefers-reduced-motion` compliance.
- **Mobile Hero Buttons Optimization**: Compacted "Explore Products" and "Enquire Now" button dimensions, reduced padding, and aligned side-by-side on mobile viewports to prevent viewport clutter and eliminate overlap with the floating WhatsApp icon.
- **WhatsApp Prefilled Message Integration**: Added prefilled message (`"Hi, I want to know more about your mushrooms and products. Please send me the details."`) across all floating and footer WhatsApp buttons.
- **Enquiry Form Validation & Hard Word Cap**: Implemented strict submit-time validation state machine and a 150-word hard limit on textarea input with live progressive color-coded counter feedback.
- **Social Media Updates**: Replaced legacy Twitter/X links with official MushClub Facebook profile (`https://www.facebook.com/themushclub.in`).
- **Cache & Service Worker**: Upgraded Service Worker cache to `mushclub-cache-v28` and asset query versioning across all HTML documents.
